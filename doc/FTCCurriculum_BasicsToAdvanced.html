FTC Robotics Curriculum Outline

This curriculum is designed to be a guided, task-based program for First Tech Challenge (FTC) robotics. The goal is to provide students with a series of challenges that encourage independent problem-solving and collaboration, rather than direct instruction.

Software

Primary Resource: Learn Java for FTC (PDF) | Learn Java for Robotics (FTC) – Brogan Pratt (playlist)

Philosophy: This curriculum follows a fundamentals-first approach inspired by Brogan M. Pratt's teaching philosophy: build core understanding of control theory, custom implementations, and debugging before introducing helper libraries. Master the underlying principles first, then use tools that abstract them.

Software.Course1: Introduction to Java for FTC (10 Sessions)

Goal: To establish a strong foundation in Java programming concepts, the basic structure of an FTC robot program, and essential team collaboration workflows.

  • Software.Course1.Session1 (Est. 2 hours): Introduction to the Development Environment and Hardware
    • Task 1: Getting Started
      • Goal: Successfully set up the development environment.
      • Time Estimate: 30 minutes
      • Hardware Needed: Laptop or desktop computer.
      • Resource: Learn Java for FTC - Introduction and Now you try.
    • Task 2: Understand the Driver Station
      • Goal: Learn how the Driver Station (Android phone) interacts with the Control Hub and displays telemetry.
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone with the app installed.
      • Resource: Learn Java for FTC - Driver Station and Hello, World. (Resource: FTC-docs)
    • Task 3: Variables and Data
      • Goal: Create variables for motor power and sensor readings, and display their values on the Driver Station.
      • Time Estimate: 30 minutes
      • Hardware Needed: Driver Station phone, Control Hub.
      • Resource: Learn Java for FTC - Variables and Data Types.
  • Software.Course1.Session2 (Est. 2.5 hours): Basic Programming Concepts
    • Task 1: Perform calculations
      • Goal: Write code to scale a sensor reading to a desired motor power value.
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone, Control Hub.
      • Resource: Learn Java for FTC - Basic Math.
    • Task 2: Basic Control Flow
      • Goal: Use an if/else statement to change the robot's behavior based on a condition, such as a gamepad button press.
      • Time Estimate: 1.5 hours
      • Hardware Needed: Driver Station phone, Gamepad.
      • Resource: Learn Java for FTC - Making decisions.
  • Software.Course1.Session3 (Est. 2.5 hours): Gamepad Control
    • Task 1: Create a loop
      • Goal: Use a while loop to continuously read and update sensor values or motor power while the OpMode is running.
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone, Control Hub.
      • Resource: Learn Java for FTC - While.
    • Task 2: Gamepad and Tele-Op
      • Goal: Write a program that reads input from the gamepad's joysticks and buttons and displays the values on the telemetry.
      • Time Estimate: 1.5 hours
      • Hardware Needed: Driver Station phone, Gamepad.
      • Resource: Learn Java for FTC - Gamepad and basic math.
  • Software.Course1.Session4 (Est. 1.5 hours): Controlling a Single Motor
    • Task 1: Control a single motor
      • Goal: Use gamepad input to control the speed and direction of one motor.
      • Time Estimate: 1.5 hours
      • Hardware Needed: Driver Station phone, Gamepad, Control Hub, one motor.
      • Resource: Learn Java for FTC - Motors.
  • Software.Course1.Session5 (Est. 1.5 hours): Motors and Hardware Mapping
    • Task 1: Motors and Hardware Mapping
      • Goal: Create a HardwareMap to correctly identify and access your robot's motors, servos, and sensors.
      • Time Estimate: 1.5 hours
      • Hardware Needed: Driver Station phone, Control Hub.
      • Resource: Learn Java for FTC - Configuration file and HardwareMap.
  • Software.Course1.Session6 (Est. 3 hours): Drivetrain and LinearOpMode
    • Task 1: Control a four-motor drivetrain
      • Goal: Use gamepad input to control the speed and direction of a standard four-motor tank or arcade drive.
      • Time Estimate: 2 hours
      • Hardware Needed: Driver Station phone, Gamepad, Control Hub, four motors.
      • Resource: Learn Java for FTC - 4 motor mecanum drive.
    • Task 2: Driving Basics and LinearOpMode
      • Goal: Write a program that uses motor encoders to drive the robot a specific distance.
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone, Gamepad, Control Hub, four motors with encoders.
      • Resource: Learn Java for FTC - Motor as Sensor.
  • Software.Course1.Session7 (Est. 2.5 hours): Subsystems and Servos
    • Task 1: Understand LinearOpMode
      • Goal: Convert a basic OpMode into a LinearOpMode and understand the differences in structure and flow.
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone, Control Hub.
      • Resource: Learn Java for FTC - Linear OpMode.
    • Task 2: Introduction to Subsystems
      • Goal: Write a class that abstracts the control of a simple mechanism (e.g., a single servo claw) and its associated motors or servos.
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone, Control Hub.
      • Resource: Learn Java for FTC - Class Members and Methods and Creating your own classes.
    • Task 3: Servos and Sensors
      • Goal: Write an OpMode that uses a gamepad button to move a servo between two predefined positions.
      • Time Estimate: 30 minutes
      • Hardware Needed: Driver Station phone, Gamepad, Control Hub, one servo.
      • Resource: Learn Java for FTC - Servos.
  • Software.Course1.Session8 (Est. 2.5 hours): Integrating and Testing
    • Task 1: Integrate your subsystem
      • Goal: Add the subsystem you created into your main tele-op program and control it with the gamepad.
      • Time Estimate: 1.5 hours
      • Hardware Needed: Driver Station phone, Gamepad, Control Hub, at least one motor and servo.
      • Resource: Learn Java for FTC - Mechanisms.
    • Task 2: Read a sensor
      • Goal: Use a color, distance, or touch sensor to make a decision in your code (e.g., stop the robot when it is a certain distance from a wall).
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone, Control Hub, a sensor (color, distance, or touch).
      • Resource: Learn Java for FTC - Analog Sensors and Color and Distance Sensors.
  • Software.Course1.Session9 (Est. 3 hours): Autonomous Fundamentals and State Machines
    • Task 1: Autonomous Fundamentals
      • Goal: Write a simple autonomous program that uses getRuntime() to move the robot forward for a set amount of time.
      • Time Estimate: 1 hour
      • Hardware Needed: Driver Station phone, Control Hub, motors.
      • Resource: Learn Java for FTC - It's all relative.
    • Task 2: Understanding State Machines
      • Goal: Learn the concept of state machines and how they help organize complex sequential behaviors.
      • Time Estimate: 30 minutes
      • Hardware Needed: Computer.
      • Resource: State Machines – Brogan Pratt and Learn Java for FTC - Dealing with State.
    • Task 3: Implement a Basic State Machine
      • Goal: Create a simple state machine using enums to control a sequence of autonomous actions (e.g., DRIVE_FORWARD → TURN → STOP).
      • Time Estimate: 1.5 hours
      • Hardware Needed: Driver Station phone, Control Hub, motors.
      • Resource: Learn Java for FTC - Autonomous state and Using the switch statement.
  • Software.Course1.Session10 (Est. 3 hours): Git Workflow and Code Review
    • Task 1: Git Basics and Branching
      • Goal: Initialize a Git repository, create a personal branch, make commits, and push to a remote repository. Understand the GitHub Flow workflow.
      • Time Estimate: 1.5 hours
      • Hardware Needed: Computer with Android Studio and Git installed.
      • Resource: GitHub Flow, FTC Docs – Fork & Clone, and Android Studio Git Basics.
    • Task 2: Code Review and Pull Requests
      • Goal: Open a pull request with your changes, review a teammate's code, and understand best practices for code organization and documentation.
      • Time Estimate: 1 hour
      • Hardware Needed: Computer.
      • Resource: About Pull Requests, Review PRs in Android Studio, Learn Java for FTC - Comments, and Javadoc.
    • Task 3: Debugging Practice
      • Goal: Intentionally introduce an error into your code and use the debugger to find and fix it.
      • Time Estimate: 30 minutes
      • Hardware Needed: Computer, Driver Station phone, Control Hub.
      • Resource: Learn Java for FTC - Gotchas.

    Software.Course2: Advanced Robotics Programming (10 Sessions)

    Goal: To master advanced programming techniques through fundamentals-first learning: custom PID control, FTC Dashboard tuning, odometry integration, field visualization, and advanced state machines. After building these skills from scratch, students will learn industry-standard libraries (Road Runner, MeepMeep, FTCLib) that abstract these concepts.

    Core Philosophy: Practice the underlying principles of RR, MeepMeep, and FTCLib before using them. Build custom implementations to understand how they work, then leverage libraries for efficiency.

    • Software.Course2.Session1 (Est. 3 hours): Mecanum Drive Fundamentals
      • Task 1: Understanding Mecanum Drive Theory
        • Goal: Learn how Mecanum wheels work, the physics behind holonomic movement, and how to calculate motor powers for robot-centric and field-centric control.
        • Time Estimate: 1 hour
        • Hardware Needed: Computer, whiteboard/paper for vector diagrams.
        • Resource: Learn Java for FTC - 4 motor mecanum drive, GM0 - Mecanum Drive Tutorial.
      • Task 2: Implement Custom Mecanum Drive
        • Goal: Write a tele-op program from scratch that calculates motor powers for strafing, forward/backward, and rotation. Manually implement the math without using libraries.
        • Time Estimate: 2 hours
        • Hardware Needed: Driver Station phone, Gamepad, Control Hub, four Mecanum wheels with motors.
        • Resource: Learn Java for FTC - Mecanum Mechanism, GM0 - Mecanum Drive.
    • Software.Course2.Session2 (Est. 3 hours): PID Control Theory and Implementation
      • Task 1: Understanding PID Control
        • Goal: Learn the theory behind PID controllers: Proportional, Integral, and Derivative terms, how they work together, and when to use each component.
        • Time Estimate: 1 hour
        • Hardware Needed: Computer.
        • Resource: PID Control Explained, GM0 - Control Loops, CTRL ALT FTC - PID.
      • Task 2: Build a Custom PID Class
        • Goal: Implement a reusable PID class from scratch with Kp, Ki, Kd gains, integral windup protection, and optional feedforward (kG). Do NOT use any library—build it yourself.
        • Time Estimate: 1.5 hours
        • Hardware Needed: Computer.
        • Resource: Implementing PID in FTC, CTRL ALT FTC - PID.
      • Task 3: Test PID on a Simple Motor
        • Goal: Apply your custom PID controller to hold a motor at a target encoder position or velocity. Observe how changing Kp, Ki, and Kd affects behavior.
        • Time Estimate: 30 minutes
        • Hardware Needed: Driver Station phone, Control Hub, motor with encoder.
        • Resource: Learn Java for FTC - Motor as Sensor.
    • Software.Course2.Session3 (Est. 3 hours): FTC Dashboard Setup and Live Tuning
      • Task 1: Install and Configure FTC Dashboard
        • Goal: Add the FTC Dashboard dependency to your project, initialize it, and connect via Wi-Fi to view live telemetry in a web browser.
        • Time Estimate: 1 hour
        • Hardware Needed: Computer, Driver Station phone, Control Hub.
        • Resource: FTC Dashboard Documentation.
      • Task 2: Use @Config for Live Variable Tuning
        • Goal: Add @Config annotation to your PID class to expose Kp, Ki, Kd as live-tunable variables. Create telemetry graphs to visualize target, current value, error, and output.
        • Time Estimate: 1 hour
        • Hardware Needed: Computer, Driver Station phone, Control Hub.
        • Resource: FTC Dashboard @Config Tuning, FTC Dashboard Docs.
      • Task 3: Tune Drivetrain PID Controllers
        • Goal: Apply PID tuning methods (Ziegler-Nichols or manual) to tune heading hold and drive straight controllers for your drivetrain. Use Dashboard graphs to observe system response.
        • Time Estimate: 1 hour
        • Hardware Needed: Driver Station phone, Control Hub, drivetrain with encoders and IMU.
        • Resource: Tuning Methods (Ziegler-Nichols), GM0 - Control Loops.
    • Software.Course2.Session4 (Est. 3 hours): IMU and Odometry Integration
      • Task 1: IMU-Based Heading Control
        • Goal: Use the robot's IMU to read heading (yaw) and implement a heading-hold PID controller. Test by commanding the robot to maintain a heading while being pushed.
        • Time Estimate: 1.5 hours
        • Hardware Needed: Driver Station phone, Control Hub with IMU, drivetrain.
        • Resource: Learn Java for FTC - Gyro (IMU), FTC Docs - IMU.
      • Task 2: Integrate Pinpoint Odometry Computer
        • Goal: Add the GoBilda Pinpoint driver to your project, configure the device, set TICKS_PER_MM, and verify encoder directions. Get accurate X, Y, and Heading pose updates.
        • Time Estimate: 1 hour
        • Hardware Needed: Driver Station phone, Control Hub, GoBilda Pinpoint Odometry Computer with two odometry pods.
        • Resource: Pinpoint Product Page, Pinpoint Driver, Pinpoint Example OpMode.
      • Task 3: Validate Pose Tracking
        • Goal: Run an OpMode that continuously updates and displays the robot's Pose2d (X, Y, Heading). Manually push the robot and verify the pose changes correctly.
        • Time Estimate: 30 minutes
        • Hardware Needed: Driver Station phone, Control Hub, Pinpoint odometry.
        • Resource: Pose2d API Reference (Note: Pose2d is just a data class—it doesn't control motion).
    • Software.Course2.Session5 (Est. 3 hours): Field Visualization and Path Debugging
      • Task 1: Draw Robot on Field View
        • Goal: Use FTC Dashboard's field view to render the robot's position and orientation as a rectangle on a virtual field. Update the drawing in real-time using Pose2d from Pinpoint.
        • Time Estimate: 1.5 hours
        • Hardware Needed: Driver Station phone, Control Hub, Pinpoint odometry.
        • Resource: FTC Dashboard - Field View, Pose2d API.
      • Task 2: Visualize Planned vs Actual Paths
        • Goal: Draw a planned autonomous path (e.g., waypoints or simple line segments) on the field view, then overlay the robot's actual movement to debug trajectory following.
        • Time Estimate: 1 hour
        • Hardware Needed: Driver Station phone, Control Hub, Pinpoint odometry.
        • Resource: FTC Dashboard - Field View.
      • Task 3: Test and Refine Visualization
        • Goal: Run the robot through a test autonomous routine and verify that the field visualization accurately represents the robot's position and orientation.
        • Time Estimate: 30 minutes
        • Hardware Needed: Driver Station phone, Control Hub, Pinpoint odometry, drivetrain.
        • Resource: FTC Dashboard field view examples.
    • Software.Course2.Session6 (Est. 3 hours): Advanced State Machines and Autonomous
      • Task 1: Build Reusable State Machine Template
        • Goal: Create a robust state machine framework with ENTER, EXECUTE, and EXIT phases for each state. Use enum states with switch statements for clarity and maintainability.
        • Time Estimate: 1.5 hours
        • Hardware Needed: Computer.
        • Resource: State Machines - Brogan Pratt, Learn Java for FTC - Dealing with State, Using the switch statement.
      • Task 2: Implement Multi-Step Autonomous with Pose Feedback
        • Goal: Write an autonomous program that uses your state machine to navigate to multiple waypoints using Pose2d feedback (e.g., DRIVE_TO_WAYPOINT_1 → TURN_TO_HEADING → DRIVE_TO_WAYPOINT_2 → STOP).
        • Time Estimate: 1 hour
        • Hardware Needed: Driver Station phone, Control Hub, drivetrain, Pinpoint odometry.
        • Resource: Methods/Functions - Brogan Pratt, state machine resources from Session 1.9.
      • Task 3: Integrate Subsystems into Autonomous
        • Goal: Add subsystem control (e.g., intake, lift, launcher) into your state machine states, with proper sequencing and safety checks.
        • Time Estimate: 30 minutes
        • Hardware Needed: Driver Station phone, Control Hub, subsystem motors/servos.
        • Resource: Learn Java for FTC - Mechanisms.
    • Software.Course2.Session7 (Est. 3 hours): Vision Processing and AprilTags
      • Task 1: Computer Vision Fundamentals
        • Goal: Learn the basics of computer vision: cameras, image processing, and how vision is used in FTC for game element detection and localization.
        • Time Estimate: 1 hour
        • Hardware Needed: Computer, webcam or phone camera.
        • Resource: Learn Java for FTC - Computer Vision.
      • Task 2: Implement AprilTag Detection
        • Goal: Use the FTC SDK's built-in AprilTag detection to identify tags on the field and read their position/orientation data.
        • Time Estimate: 1.5 hours
        • Hardware Needed: Driver Station phone with camera, Control Hub, AprilTag printouts.
        • Resource: Learn Java for FTC - AprilTags, FTC Docs - VisionPortal.
      • Task 3: Use Vision Data in Autonomous
        • Goal: Integrate AprilTag detection into your autonomous state machine to make decisions (e.g., navigate to different waypoints based on detected tag ID).
        • Time Estimate: 30 minutes
        • Hardware Needed: Driver Station phone with camera, Control Hub, drivetrain.
        • Resource: State machine resources, AprilTag examples.
    • Software.Course2.Session8 (Est. 3 hours): Introduction to Road Runner (After Fundamentals)
      • Task 1: Understanding Road Runner's Purpose
        • Goal: Now that you've built custom PID, odometry integration, and path following, learn how Road Runner automates these tasks with motion profiling and trajectory generation.
        • Time Estimate: 45 minutes
        • Hardware Needed: Computer.
        • Resource: Road Runner Documentation, LearnRoadRunner.com.
      • Task 2: Install and Configure Road Runner
        • Goal: Integrate the Road Runner library into your FTC project, configure drive constants, and understand the tuning process (but note: you already understand what it's doing under the hood!).
        • Time Estimate: 1.25 hours
        • Hardware Needed: Computer, Driver Station phone, Control Hub.
        • Resource: Road Runner Docs, Road Runner Quickstart guide.
      • Task 3: Create a Simple TrajectorySequence
        • Goal: Use Road Runner's TrajectorySequence builder to program a simple autonomous path (straight line, turn, curve). Compare the effort to your custom implementation.
        • Time Estimate: 1 hour
        • Hardware Needed: Driver Station phone, Control Hub, drivetrain with odometry.
        • Resource: Road Runner Docs.
    • Software.Course2.Session9 (Est. 3 hours): MeepMeep and Advanced Trajectories
      • Task 1: Visualize Paths with MeepMeep
        • Goal: Use MeepMeep to visually design and test complex autonomous trajectories with splines, turns, and multiple waypoints before deploying to the robot.
        • Time Estimate: 1.5 hours
        • Hardware Needed: Computer with web browser.
        • Resource: MeepMeep Tool, MeepMeep GitHub.
      • Task 2: Transfer and Test Trajectories
        • Goal: Convert MeepMeep-designed trajectories into your robot code using Road Runner. Test and refine on the physical robot.
        • Time Estimate: 1 hour
        • Hardware Needed: Driver Station phone, Control Hub, drivetrain.
        • Resource: Road Runner Docs, MeepMeep examples.
      • Task 3: Build a Competition-Ready Autonomous
        • Goal: Create a full autonomous routine that combines Road Runner trajectories, state machine logic, subsystem control, and vision feedback for a complete competition strategy.
        • Time Estimate: 30 minutes
        • Hardware Needed: Driver Station phone, Control Hub, full robot.
        • Resource: All previous session resources.
    • Software.Course2.Session10 (Est. 3 hours): Introduction to FTCLib (After Fundamentals)
      • Task 1: Understanding FTCLib's Role
        • Goal: Learn how FTCLib provides command-based programming, advanced motor controllers, and utility classes that abstract concepts you've already implemented (PID, subsystems, etc.).
        • Time Estimate: 45 minutes
        • Hardware Needed: Computer.
        • Resource: FTCLib Documentation, FTCLib Command System.
      • Task 2: Integrate FTCLib into Your Project
        • Goal: Add FTCLib dependency and refactor one subsystem (e.g., drivetrain or lift) to use FTCLib's motor wrappers and command-based structure.
        • Time Estimate: 1.25 hours
        • Hardware Needed: Computer, Driver Station phone, Control Hub.
        • Resource: FTCLib Docs, FTCLib Hardware Classes.
      • Task 3: Compare Custom vs Library Implementations
        • Goal: Reflect on the trade-offs: custom code gives you full control and deep understanding, while libraries (RR, MeepMeep, FTCLib) save time and reduce bugs. Discuss when to use each approach.
        • Time Estimate: 1 hour
        • Hardware Needed: Computer.
        • Resource: Team discussion, review of code examples from previous sessions.

    Goal: To synthesize all skills by designing, building, and programming a complete robot for a past FTC game.

    • Combined.Session1 (Est. 3 days): Robot Concept and CAD
      • Task 1: Game Analysis
        • Goal: Break down the rules and objectives of a past FTC game. Identify key scoring elements, field hazards, and robot requirements.
        • Time Estimate: 1 day
        • Hardware Needed: None.
        • Resource: Analyzing and Breaking Down the 2026 FTC Game.
      • Task 2: Integrated Robot Concept
        • Goal: As a team, create a single document outlining the robot's design concept, including a sketch of the chassis and a description of the planned mechanisms.
        • Time Estimate: 1 day
        • Hardware Needed: None.
        • Resource: Designing Our FTC Bot 2023-2024 \- Instructables.
      • Task 3: Full Robot CAD
        • Goal: The CAD team must design the complete robot in Onshape, including the drivetrain and all subsystems, ensuring they fit together correctly and can be built with available parts.
        • Time Estimate: 1 day
        • Hardware Needed: Computer with a web browser.
    • Combined.Session2 (Est. 3 days): Full Robot Code
      • Task 1: Full Robot Code
        • Goal: The software team must write a comprehensive program for the robot, including a robust tele-op and an autonomous mode that uses Road Runner and state machines to complete game objectives.

        • Hardware Needed: Computer, Driver Station phone, Gamepad, Control Hub.
    • Combined.Session3 (Est. 2 days): Build and Test
      • Task 1: Final Build and Test
        • Goal: As a team, assemble the physical robot from the CAD models and test all its functions.

        • Goal: Run the robot through a mock competition to evaluate its performance and prepare for a real event.
